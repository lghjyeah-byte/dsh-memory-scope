# 大肥鱼长期记忆：Memory Scope

一个安装在 DeepSeek Harness（大肥鱼）里的长期记忆插件，支持**办公工作区共享**与**聊天范围隔离**。不依赖 Codex、QQ 桥接、SnowLuma 或特定 QQ 机器人。

> **测试版**：已在隔离的 Harness 0.1.7-rc.2 和虚拟模型中验证摘要、工作区共享、新会话继承、范围隔离和超时保护。不同模型、不同版本及真实 QQ 桥接尚未完成兼容性验证；请保留原始对话，不要把插件视为备份。

## 功能

- **办公记忆**：将某个记忆范围绑定到工作区目录，目录及其子目录的会话可以共享这份摘要。
- **聊天记忆**：每个范围可绑定指定会话，不同范围分开保存。创建新会话时，可使用“整理记忆并创建新会话”，新会话自动绑定同一范围，旧会话保留。
- **摘要管理**：可以查看、编辑、清空摘要，也可以让当前会话选用的模型整理对话。摘要主要保存重要偏好、事实和延续事项，不逐字保存整段聊天。
- **自动整理**：每个范围可单独启用。默认关闭；启用后，当一个绑定会话累计约 30 条新消息且空闲时调用模型整理。
- **失败保护**：模型超时、输出截断、摘要格式错误或证据不匹配时，不覆盖原摘要；创建新会话前整理失败时也不会创建。

## 安装

需要支持插件的 DeepSeek Harness 和 Node.js 22 或更新版本。安装仓库版本的通用命令：

```bash
dsh plugin --profile <你的profile> add github:lghjyeah-byte/dsh-memory-scope
```

实际 profile 名称取决于安装方式；部分桌面版不能直接从 GitHub 安装插件。安装后在大肥鱼侧边栏或设置中查找“长期记忆”。仓库发布不等于自动收录进插件市场，市场收录与安装方式由相应平台决定。

## 使用

1. 在“长期记忆”创建范围：英文标识例如 `office`，显示名称例如“办公”。
2. 选择范围和已打开的会话，点击“绑定会话”；办公用途也可以填入工作区绝对路径并点击“绑定办公工作区”。
3. 在摘要框填写或编辑记忆；也可以点击“整理已绑定会话并保存记忆”。如需自动整理，在该范围勾选开关。
4. 希望换新上下文时，选中原会话和范围，点击“整理记忆并创建新会话”。从侧边栏打开创建的新会话即可继续。

## 隔离与限制

- **办公工作区范围会影响所选目录和子目录的会话。**不要把包含群聊或他人私聊的目录绑定到办公记忆，否则他们可能通过回复看到办公信息。默认没有绑定，不会向未选范围的会话注入记忆。
- 原生插件不会猜测外部 QQ 桥接的好友或群对应哪个新会话。QQ 桥接自行新建会话后，通常需要在插件中重新绑定；具体桥接的自动切换**没有承诺或验证**。插件里的新建会话按钮不会自动更改外部 QQ 桥接的会话绑定。
- 解除绑定不能移除已经进入该会话上下文的记忆；请在新会话中切换范围。新建会话使用大肥鱼的默认模型设置，未保证继承原会话的独立模型设置。
- 模型摘要可能遗漏或误解内容。依据检查只能拒绝部分错误，不能证明摘要完全正确；建议在页面中查看和修改。
- 模型整理会把待整理对话发送给当前选用的模型提供方并消耗额度。自动整理默认关闭；单次模型调用最长等待约 30 秒，超时后不更新原记忆。
- 尽管会排除部分明显密钥与密码格式，不能保证识别所有敏感信息。请勿把密码、验证码、密钥等输入记忆；本机记忆文件属于用户数据，不应上传公开仓库。
- 暂不自动导入其他插件或 QQ 桥接中已有的记忆，也不保证记忆包含每句话或每张图片。

## 存储

摘要与绑定信息存于大肥鱼数据目录下的 `memory-scope/memory.json`，独立于源码和本仓库；更换或删除对话不会自动删除这个文件。请根据需要自行备份。

## 隔离验证

使用相同 Harness 版本和虚拟模型，验证了插件加载、模型摘要、新会话绑定、办公范围共享、聊天范围隔离、模型超时期间宿主仍响应，以及跨站写入被拒绝。真实模型的输出可能不符合摘要格式，或超过超时限制；该路径仍需继续验证。
